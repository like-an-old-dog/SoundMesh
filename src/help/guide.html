第一次把手机和电脑连起来

以「安卓手机播放音乐，耳机连在 Windows 电脑上」为例。

  1. 在电脑上完整解压 Windows 包，运行 Windows/SoundMesh.exe。让 SoundMeshCapture.exe 留在同一文件夹。安卓安装声汇 APK。
  2. 电脑和手机连到同一局域网。电脑可以插网线，手机可以用 Wi-Fi，只要两台设备能互相访问。把耳机连接电脑，并选为 Windows 的声音输出。
  3. 两端各点一次开始融合。安卓弹出系统录制或投射授权时，按系统提示允许共享你要听的应用声音。
  4. 电脑打开设备连接，点刷新，选中手机后点连接所选设备。首次配对输入手机「设备连接」中显示的八位配对码。
  5. 电脑打开输出设置 → 把监听切到本机。手机播放一段音乐，电脑打开混音台，找到手机名称，拖动它的音量。
听到手机音乐，且拖动手机那一行只改变它在耳机里的响度，就完成了第一次融合。

扫码、手动配对和第三台设备

安卓扫码。 两端先开始融合。在一端的「设备连接」点「显示配对二维码」，另一台安卓设备在声汇里点「扫码连接」。Windows 也可以用「读取二维码图片」载入对端的配对码图片。

手动配对。 在对端查看局域网 IPv4 地址和八位配对码，在本机的「设备连接 → 手动配对」输入两项。记住配对的设备，下次可以从附近列表选择。

加入平板。 以手机、电脑、平板为例，先连手机与电脑，再连平板与电脑、平板与手机。每对只需配对一次即可双向收发。之后任一台接管监听，都能收到另外两台的声音。

把耳机切到另一台设备

  1. 把耳机连接到新的监听设备，在系统声音设置或控制中心选中该耳机。
  2. 在这台设备的输出设置点把监听切到本机。声汇会开启本机监听，并通知已连接的对端暂停监听。
  3. 分别播放两台设备的声音，确认都从耳机传出。双设备蓝牙耳机还可能需要在系统中切换当前音频输出。

结束使用时点「结束融合」。仅需移除某一台时，在混音台该设备的卡片点「移除」或「断开设备」。

选对音量滑杆

只想把耳机里的某台设备调小
在耳机所在设备的混音台，拖动那台远端设备名称下的滑杆。点该行「静音」可单独试听其他设备。
想让其他人听到的本机声音更小
在声音来源设备上拖动「本机发送」或「本机 · 发给其他设备」。所有正在接收这一路的设备都会听到变化。
想一起调低全部远端声音
在监听端拖动「其他设备合计」或「远端混音总音量」。各路之间原先的相对音量保留。
想调本机自己播放的声音
Windows 用「本机应用」，安卓用「本机 · 系统媒体输出」。安卓这条控制系统媒体音量，也会影响耳机里的混音。部分机型降低媒体音量后，采集声音也会变小。

快捷调音。 Windows 按 Ctrl+Alt+M 打开音量小窗，选择设备后拖动，Esc 收起。安卓下拉并展开声汇媒体卡片，拖动滑杆调远端混音总音量，点卡片打开逐设备面板。Android 13 及以上请允许通知。紧凑布局可能需要先展开卡片。

卡顿时怎样选缓冲

在耳机所在设备 → 输出设置 → 播放缓冲选档。Windows 和安卓 1.2 及以上的远端音轨支持按时间戳对齐。

同步 150 ms · 默认
第一次使用先选这一档。播放同一段内容，留意远端设备的「断流」计数是否继续增长。
同步 200 ms · 多留一些等待时间
偶发卡顿且断流次数增加时，切到这一档，再听同一段内容。
同步 100 ms · 缩短等待
播放稳定但看视频觉得声音偏晚时试这一档。如果断流增多，调回 150 ms。

25、70、90 ms 为独立缓冲档。与旧版设备混连时，旧设备使用独立缓冲。本机应用直接由系统播放。耳朵实际听到声音的延迟还包含系统播放和蓝牙耳机本身的缓冲。

用 iPhone 的 Safari 监听

  1. 在同一 Wi-Fi 的 Windows 电脑开始融合，打开设备连接 → 邀请 iPhone 网页监听。
  2. 用 iPhone 系统相机扫弹出的网页邀请二维码，在 Safari 点「开始监听」。将耳机连到 iPhone，并在控制中心选中耳机。
  3. 要加入其他来源，点网页「添加设备」，选择附近设备或输入发送端地址和配对码。各设备可在网页混音台独立调音。

试听时保持 Safari 页面打开。Windows 结束融合后，旧邀请失效；下次请扫新的网页邀请。浏览器只能接收音频。发送 iPhone 应用声音需使用原生开发版，由 Mac 编译签名，尚待真机验证。

搜不到设备、已连接却无声

搜不到设备或连接超时
确认两端都已点「开始融合」。检查是否接入访客 Wi-Fi、隔离热点或 VPN。改用扫码或手动配对时，选发送设备实际使用的 Wi-Fi／以太网地址。电脑有虚拟网卡时尤其容易选错。Windows 防火墙应允许声汇通过当前可信专用网络。
提示配对失败
确认输入的是对端的八位码。删除列表里的旧通道，从「设备连接」重新选择或扫码。设备换网后也需要用新地址连接。
混音台有设备，耳机却无声
先确认系统输出选对了耳机，并在声汇点「把监听切到本机」。检查远端通道是否静音、远端总音量是否为零，再看发送端的「本机发送」。安卓可换一个允许采集的音乐或游戏应用测试；通话、受保护的内容可能无声。
电脑开始融合时提示采集失败
确认已完整解压且两个 EXE 在同一目录。正式双向模式要求支持进程隔离采集的 Windows x64 build 20348 或更高版本；常见适用系统为 Windows 11。
配对成功，但声音时断时续
先对照「卡顿时怎样选缓冲」排查，再检查 Wi-Fi 信号和系统是否限制声汇后台运行。排查网络规则时，设备发现用 UDP 49633，音频用 TCP 49632，iPhone 网页入口用 TCP 49634。请在可信局域网内使用。
